# 🏢 Real Estate Executive Performance & Regional Deep-Dive Suite

Large-scale Power BI analytics platform processing 1.05M+ real estate records across revenue, town performance, property type distributions, and granular matrix trends.


## 📌 Executive Overview
This project presents an enterprise-grade, 2-page interactive **Power BI Dashboard** analyzing a comprehensive dataset comprising **over 1.05 million property sales records**.

The primary goal of this analytics engine is to provide real estate executives and regional leads with actionable visibility into revenue generation, town-level performance, and property category distributions totaling **₦418 Billion in total transaction volume**.


## 📊 Core KPI Scorecard (Page 1)

| Metric | Metric Value | Executive Context |
| :--- | :--- | :--- |
| Total Sales Revenue | ₦418 Billion | Cumulative financial valuation of processed property sales |
| Total Properties Sold | 1.05 Million | High-volume dataset scale across all property categories |
| Average Property Price | ₦396.6K | Macro baseline unit price benchmark across target regions |


## 💡 Key Strategic Insights
* **Top Revenue Drivers:** Single-family housing and multi-family residences generate over **68% of total gross sales volume**.
* **Regional Outliers:** Top 5 performing towns account for **>40% of total transactions**, highlighting key geographic investment hotspots.
